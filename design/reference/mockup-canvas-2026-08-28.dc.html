ACE

Mobile app — mockup board

All 19 spec screens plus the reworked order-placing flow, rendered per screen for iOS and Android (same design, platform chrome differs). Sections follow the demo scripts. Static frames — not clickable, by request.

Assumptions & design reasoning
· Pure black / bright white per your final call — Ace jet #0d0d0d–#2b2b2b on #f4f4f4, Poppins throughout. Orange dropped.
· 3D soft-depth look from your reference shots: rounded cards, deep soft shadows, glossy black hero cards, pill controls — replaces Ace's flat square web treatment for this mobile surface.
· Color only where it means something: the spec's phase/delivery/payment badge map, overdue red, due-today amber, stock warnings, graphs. Everything else is mono.
· Sales Head appears only where the screen actually differs (home, orders, read-only detail).
· States shown inline on the screens where they matter; product search gets loading + empty frames.
· Today = 12 Aug 2026 · FY 26-27 · dataset from spec §3.
Login → Home ─┬ Orders → Order detail ─┬ Timeline │ ├ Record delivery │ ├ Record payment │ └ Return / Exchange ├ + New order: Customer → Products │ → Variant & qty → Cart → Review │ → Success → Order detail ├ Customers → Detail (ledger / actions) └ More → Profile / Logout
